# Ecological Indicator Inventory (EII)

**Status:** Stage A — living reference inventory.

EII is an independent inventory of ecological variables, indicators, indices and inferences. Its current scope includes landscape, GIS and remote sensing, point clouds, soil, microbiomes, ecological processes and socio-ecological context.

Read [the inventory](EII.md) for the scope, stable IDs, register and interpretation notes. The inventory is exploratory; scientific verification, bibliographic enrichment and database implementation are later stages.

EII develops independently of EIRKB and AMRKB, with future interoperability through compatible identifiers, source metadata and explicit relationships.

## Local maintenance

Open this directory as the project workspace. Keep version notes inside documents and use Git history for revisions. No remote repository is configured.
